# LIT Energy: стартовый набор для Claude Code

Задача: интерфейс мобильного приложения LIT Energy (Telegram Mini App) без бэкенда, на тестовых данных, в новом дизайне.

## Шаги

### Шаг 1. Положить папку
Распакуй архив, например в `~/Projects/lit-app`.

### Шаг 2. Поставить навыки в Claude Code (один раз)
Открой терминал и выполни:

```
cd ~/Projects/lit-app
bash install-skills.sh
```

Скрипт скопирует в `~/.claude/skills` шесть навыков: impeccable, emil-design-eng, mobile-native, apple-design, animate и наш lit-energy-design. Навык design-taste-frontend у тебя уже стоит.

### Шаг 3. Положить дизайн
Выгрузи экраны из вкладки дизайна в папку `design/new/`:
- каждый экран картинкой PNG, названия по смыслу: `home-morning.png`, `home-day.png`, `home-evening.png`, `tasks.png`, `league.png`, `shop.png`, `case-open.png`...;
- если вкладка отдаёт HTML или код экрана, клади его туда же с тем же именем (`home-day.html`).

В `design/current-app/` лежат три экрана текущего приложения — только для сравнения, визуал оттуда не берём.

### Шаг 4. Запустить Claude Code
```
cd ~/Projects/lit-app
claude
```
Claude Code сам прочитает `CLAUDE.md` с правилами проекта.

### Шаг 5. Вести по шагам
Открой `PROMPTS.md` и вставляй промпты по одному. После каждого шага смотри результат в браузере и только потом переходи к следующему.

## Что в папке

| Путь | Что это |
| --- | --- |
| `CLAUDE.md` | Правила проекта для Claude Code: стек, структура, порядок работы, запреты |
| `DESIGN.md` | Дизайн-система: цвета, шрифты, отступы, компоненты, анимации |
| `PROMPTS.md` | Готовые промпты по шагам |
| `PRODUCT.md` | Механики и логика экранов: заряд, стрик, задания, лиги, сезон, кейсы, буст от чека |
| `data/mock.json` | Тестовые данные: игрок, баланс, задания, лига, кейсы, дроп |
| `assets/` | Фирменная графика: монеты, кейс, персонаж, логотип, баннер |
| `design/new/` | Сюда — экраны из вкладки дизайна |
| `design/current-app/` | Текущее приложение, для сравнения |
| `skills/` | Навыки для установки |
| `install-skills.sh` | Скрипт установки навыков |

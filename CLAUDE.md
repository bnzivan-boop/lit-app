# LIT Energy — мобильное приложение (фронтенд)

## Что делаем
Интерфейс приложения бренда энергетиков LIT Energy. Это Telegram Mini App: открывается внутри Telegram на телефоне. Бэкенда нет: все данные — моки из `data/mock.json`, действия меняют локальное состояние. Цель — кликабельный, красивый и понятный интерфейс уровня 2026 года, который можно показать бизнесу и потом подключить к API.

Аудитория: 18–25 лет, геймеры, студенты, спортсмены. Язык интерфейса — русский.

## Источники правды (читать перед любой работой)
1. `DESIGN.md` — дизайн-система. Цвета, шрифты, отступы и компоненты берём только оттуда.
2. `PRODUCT.md` — механики и логика экранов.
3. `design/new/` — макеты экранов из Claude Design. Верстаем по ним. Если макет противоречит `DESIGN.md`, спроси, а не выбирай молча.
4. `design/current-app/` — старое приложение. Только для понимания, визуал оттуда НЕ брать.

## Навыки
- `lit-energy-design` — наши правила бренда. Используй всегда.
- `impeccable` — главный навык для дизайна и вёрстки интерфейса, аудита и полировки.
- `mobile-native` — всё, что касается телефона и WebView: вырез экрана, высота экрана, тапы, скролл, зум полей ввода.
- `emil-design-eng` — детали взаимодействия: нажатия, переходы, состояния.
- `animate` — анимации (открытие кейса, прогресс, награды).
- `apple-design` — жесты, пружинные анимации, шторки.
- `design-taste-frontend` — второе мнение по визуалу. Он заточен под сайты, его правила про фото и лендинги к нам не применяй.

## Стек
- Vite + React + TypeScript.
- Стили: CSS Modules или обычный CSS с CSS-переменными из `DESIGN.md`. Без UI-библиотек с чужим стилем.
- Анимации: CSS-переходы; для сложного (рулетка кейса, пружины) — Motion (framer-motion).
- Роутинг: react-router.
- Шрифты: Roboto Condensed (700, 800) и Liter из Google Fonts.
- Telegram: подключить `telegram-web-app.js`, но приложение должно полностью работать и в обычном браузере (заглушка, если `window.Telegram` нет).

## Структура
```
src/
  tokens.css          цвета, шрифты, отступы, скругления (из DESIGN.md)
  components/         Button, Card, ProgressBar, Coin, TabBar, Header, TaskRow...

public/assets/        копия assets/
```

## Порядок работы
- Работаем по шагам из `PROMPTS.md`. Один шаг — один результат, который можно посмотреть.
- Перед большим шагом — короткий план, код после подтверждения.
- После каждого шага запусти `npm run dev` и проверь экран в ширине 390 px.
- Один экран за раз. Не трогай готовые экраны без просьбы.

## Правила интерфейса
- Ширина макета 390 px; всё должно работать от 360 до 430 px.
- На экране одна главная кнопка (тиффани). Остальные — второстепенные.
- Зоны нажатия не меньше 44×44 px.
- Тиффани — только действие и прогресс. Оранжевый — только угроза потери.
- Цифры и заголовки — Roboto Condensed ExtraBold с трекингом −5%. Остальное — Liter.
- Всегда показывай монету рядом с суммой.
- Учитывай вырез экрана и нижнюю полосу (`env(safe-area-inset-*)`).
- Уважай `prefers-reduced-motion`.

## Запрещено
Одинаковые серые карточки подряд, градиентные заливки фона, стеклянные плашки, эмодзи, мелкий серый текст, бегущие строки, дубли нижнего меню, длинные фразы капсом поверх картинки, выдуманные функции, которых нет в `PRODUCT.md`.

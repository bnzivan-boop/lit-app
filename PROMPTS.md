# PROMPTS.md — промпты по шагам

Вставляй по одному в Claude Code (запущен в папке `lit-app`). После каждого шага смотри результат в браузере, пиши правки и только потом переходи дальше.

---

## Шаг 0. Знакомство и план
```
Прочитай CLAUDE.md, DESIGN.md, PRODUCT.md и data/mock.json. Посмотри все картинки в design/new/ и design/current-app/.
Используй навыки lit-energy-design и impeccable.
Код пока не пиши. Дай мне:
1) как ты понял продукт в 5 строках;
2) список экранов и компонентов, которые нужно сделать;
3) где макеты расходятся с DESIGN.md или друг с другом — списком, с вопросами ко мне.
```

## Шаг 1. Проект и токены
```
Создай проект по стеку из CLAUDE.md. Скопируй assets/ в public/assets/.
Сделай src/tokens.css со всеми токенами из DESIGN.md и подключи шрифты.
Сделай страницу-витрину /kit, на которой видно все цвета, шрифты и размеры.
Запусти dev-сервер и скажи адрес.
```

## Шаг 2. Базовые компоненты
```
Используй навыки impeccable и emil-design-eng.
Сделай компоненты из раздела «Компоненты» DESIGN.md со всеми состояниями (обычное, нажатие, неактивное, загрузка) и покажи их на странице /kit.
Нижняя панель — с учётом safe-area.
```

## Шаг 3. Главная
```
Сверстай главную точно по design/new/home-*.png (и home-*.html, если есть).
Данные — из data/mock.json. Логика главной кнопки «Сегодня» — по PRODUCT.md.
Сделай переключатель состояний (утро / день / вечер) на /kit, чтобы я мог проверить все три.
```

## Шаг 4. Мобильность
```
Используй навык mobile-native.
Проверь и исправь главную и компоненты под телефон и Telegram WebView: вырез экрана, высота экрана, подсветка при тапе, двойной тап, зум полей ввода, скролл под нижней панелью, выделение текста долгим нажатием.
Подключи telegram-web-app.js с заглушкой для обычного браузера.
```

## Шаг 6. Открытие кейса
```
Используй навыки animate и apple-design.
Сделай открытие кейса: рулетка 3–4 секунды с сильным замедлением, линия-указатель по центру, затем экран выигрыша с цветом редкости, кнопками «Забрать» и «Открыть ещё». Списание софта и добавление предмета — в локальном состоянии.
Учитывай prefers-reduced-motion.
```

## Шаг 7. Живость
```
Используй навыки animate и emil-design-eng.
Добавь: заполнение прогресса при появлении, полёт монет к балансу при получении награды, плавный рост числа в шапке, нажатия кнопок, переходы между вкладками. Ничего лишнего: каждая анимация должна объяснять, что произошло.
```

## Шаг 8. Аудит и полировка
```
Используй навык impeccable: сначала audit, потом critique всех экранов.
Затем навык design-taste-frontend как второе мнение (только визуал; правила про сайты и фото не применяй).
Дай список проблем по важности, исправь важные и средние, мелкие покажи мне списком.
```

## Шаг 9. Сборка для показа
```
Собери продакшн-версию (npm run build) и скажи, как её открыть или выложить, чтобы показать с телефона.
```
